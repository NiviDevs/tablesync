# Contributing

Read [the documentation index](docs/README.md), [current state](docs/PROJECT_STATE.md), and [team handoff](docs/TEAM_HANDOFF.md) before taking a task. Follow [AGENTS.md](AGENTS.md).

Agree contracts and file ownership before parallel edits. Make focused changes, run the task's acceptance checks, and update [STATUS.md](docs/STATUS.md) with evidence. Update [EVENTS.md](docs/EVENTS.md) and contract tests when events change. Do not commit secrets, silently delete data, or treat archived directives as current requirements.

The rebuild specification is proposed. Review it before starting its execution plan; documentation cleanup does not authorize a database migration or deployment.
