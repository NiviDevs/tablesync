# Project

TableSync lets diners independently add menu items to a shared restaurant-table order. A table is the collaboration context: a single guest has a normal order flow; collaboration appears automatically once another participant joins.

The paying tenant is the restaurant. Customers are free. Review 1 models a platform fee and a payment ledger but performs only explicitly simulated payments.

Immediate Review 1 scope is table joining, live shared cart, item ownership, independent split checkout with a deterministic mock-provider Saga, consolidated restaurant orders and kitchen completion. Login/tenant authorization, CI and a hosted preview follow alongside stabilization. Restaurant CMS/CRM, plans, pay-later, motion and infrastructure scaling remain later phases. See STATUS.md for implemented versus pending behavior.
